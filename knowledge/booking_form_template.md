# One Stop Service — Booking Form Template

**Purpose:** This is the canonical, kept-up-to-date content for the customer-facing Google Form.
It's split into two parts:

1. **STATIC CONTENT** — policies, rules, pricing structure. Changes rarely. Kept in sync with `knowledge/faq.md` — if you update a price or policy there, update it here too (and vice versa).
2. **PER-SHOOT FIELDS** — date, location, model, logistics dates. Update this block for every new shoot.

**Workflow for each new shoot:**
1. Update the PER-SHOOT FIELDS block below with the new event's details.
2. In Google Drive, open the most recent shoot's form → **File → Make a copy** → rename (e.g. "Beach - 28 Aug").how about 
3. Paste the updated PER-SHOOT FIELDS block into the new form's date/model section (static content/questions stay as-is — don't touch them).
4. Attach the model's comp-card photos manually (not automatable from here).
5. Get the **public share link** via the form's **Send → link icon** — must start `docs.google.com/forms/d/e/...` and end `/viewform`. Do NOT share the `/edit` or `/preview` link — both require owner access and will 401 for customers.
6. Send me the new `/viewform` link so I can update `knowledge/upcoming_dates.md` and the AI's booking-link reference.

### การนับลุค / สินค้า
- เสื้อผ้า: นับต่อชุด ถ้ามีการถอดเข้า-ออก เปลี่ยนชุดนับเป็นอีกลุค (เช่น เสื้อ 2 แบบ x 3 สี = 6 ลุค)
- สินค้า: นับต่อ item/SKU (เช่น กระเป๋า 1 ใบ = 1 ลุค) เพิ่ม item ที่ 2 เข้าลุคเดิมได้สูงสุด 5 item/ลุค
- เครื่องประดับ/แว่นตา: สอบถามแอดมิน

### การถ่ายงานนอกสถานที่
1. สภาพอากาศ/ภัยธรรมชาติ ทีมงานควบคุมไม่ได้ — ฝนตกจะเลื่อนถ่ายและแจ้งลูกค้า กรณีอื่นทีมงานดำเนินการถ่ายต่อ
2. สถานที่สาธารณะที่ใช้ร่วมกับผู้อื่น มุมถ่ายหรือ background อาจมีการเปลี่ยนแปลง

### เงื่อนไขการชำระเงิน
ชำระเต็มจำนวนก่อนถ่ายงาน โอนเข้าบัญชีส่วนบุคคล กรณีหัก ณ ที่จ่าย เพิ่ม 3% ในใบเสนอราคา
